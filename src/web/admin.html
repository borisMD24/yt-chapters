Stockage en clair

La clé est enregistrée en clair dans le fichier de base de données local (le même niveau de protection que le fichier .env qu'elle remplace). Ne partagez pas ce fichier et ne le placez pas dans un dépôt ou une sauvegarde partagée.

Cache d'envoi

Les fichiers envoyés depuis la page principale y sont conservés le temps d'ajuster les bornes (7 jours par défaut). Ils ne sont plus supprimés à la fin du chapitrage. Videz le cache si vous devez libérer de l'espace : les chapitres déjà enregistrés restent inchangés, seule la réécoute du média disparaît.

Les actions d'écriture (enregistrer, supprimer, tester) ne sont possibles que depuis cet ordinateur. Retour à l'outil de chapitrage.
